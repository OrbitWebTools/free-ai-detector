# Free AI Detector — All-in-One AI Text, Image & Code Checker (No Login)

An open-source, 100% browser-based **3-in-1 Free AI Detector** built by **OrbitWebTools**. Check ChatGPT, Gemini AI, and Claude essays sentence-by-sentence, inspect AI-generated images via binary EXIF/C2PA metadata and pixel forensics, and scan source code for LLM boilerplate—with unlimited checks and zero server uploads.

🔗 **Live Web App:** [https://orbitwebtools.github.io/free-ai-detector/](https://orbitwebtools.github.io/free-ai-detector/)

---

## Key Features

* **AI Text Detector:** Analyzes sentence-length burstiness, lexical diversity (TTR), and 50+ high-frequency LLM clichés with color-coded sentence highlights (High AI / Mixed / Human-Like).
* **AI Image Detector (EXIF + C2PA + Noise Forensics):** Parses raw binary headers locally in your browser for **C2PA Content Credentials**, Stable Diffusion/ComfyUI parameters, Midjourney/DALL-E/Firefly/Imagen tags, hardware Camera EXIF presence, diffusion dimensions, and HTML5 Canvas edge-noise smoothness.
* **AI Code Detector (6 Languages):** Scans Python, JavaScript/TypeScript, Java, C/C++, PHP, and HTML/CSS for numbered tutorial comments, formal docstring templates, generic placeholder identifiers, and verbose comment ratios.
* **Unlimited & 100% Client-Side Privacy:** No account registration, no daily credit caps, and zero file uploads to remote servers.
